# Event-manager
App name: Event Manager 
Author: Charlie Koaze
Purpose: Managing Counsil Events by Elevate Horizon Connect
Project purpose: 
    1. Reduce staff time spent on manual registrations and updates
    2. Provide residents with easy access to accurate, up-to-date event information
    3. Deliver adjustable accessibility features (text size, dark mode, sound toggle)
    4. Build an MVP that can later integrate a live data context
Core features: 
    1. Fetch and display event listings (including “Today’s Events”)
    2. Search/filter events
    3. Register for events
    4. Adapt layout for mobile portrait and tablet landscape
    5. Simulate offline capability by storing latest fetched mock data locally
Deadline: 2/12/2026
